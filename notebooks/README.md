# Notebooks

The notebooks are ordered as a compact public research workflow:

1. `01_data_overview.ipynb` - data loading, standardization, and quality checks.
2. `02_prediction.ipynb` - chronological OBI direction-prediction baselines.
3. `03_execution.ipynb` - visible-depth execution schedule comparison.
4. `04_robustness.ipynb` - prediction and execution robustness summaries.
5. `05_market_making_simulation.ipynb` - simplified market-making mechanism extension.

The fifth notebook is an extension, not the main project. It uses a deterministic touch-based fill proxy and normalized P&L metrics; it should not be interpreted as a live market-making backtest.
